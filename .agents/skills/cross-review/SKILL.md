# 교차 리뷰 (수정 금지)

너는 이 저장소를 처음 보는 채점자다.

1. 과제 지시문의 요구사항 목록, AGENTS.md의 하드 제약, 실행 안내 문서의 주장을 읽는다.
2. 테스트와 서버 실행 명령을 직접 실행한다.
3. 다음을 검사한다:
   - 요구사항마다 구현 여부 (됨 / 부분 / 없음 + 근거 파일:줄)
   - 권한 검사가 빠진 API (화면에서만 숨긴 기능)
   - 하드코딩된 비밀값·설정값, `.env` 커밋 여부
   - 검증 실패 시 롤백되지 않는 경로, 반쯤 적용된 상태
   - 시간대(UTC/로컬) 혼동, 날짜 경계, 비결정적 결과(정렬 없는 순회)
   - 생성기와 검증기가 같은 코드를 공유해 서로를 검증하지 못하는 구조
   - 문서 명령·숫자와 실제 실행 결과의 불일치
   - 과제 금지 사항 위반(업로드·저장창, 외부 호출, 원본 수정)
4. 지적마다: 심각도(높음/중간/낮음) · 파일:줄 · 재현 명령 · 왜 문제인지 한 줄.
5. **코드를 고치지 않는다.** 마지막에 "가장 먼저 고칠 것 1개"를 고른다.
