# 제출 직전 게이트 (수정 금지)

아래를 **실제로 실행**하고 `항목 | 명령 | 결과 | 통과/실패` 표로 보여 준다. 실패 항목은 고치지 말고 사용자에게 알린다.

1. 과제 지시문 원본 그대로: `git diff --stat -- README*` 출력이 비어 있다
2. 원본 데이터 그대로: 제공 데이터 폴더에 `git diff --stat`이 비어 있다
3. 실행 안내·AI 협업 문서 등 과제가 요구한 문서가 있고 `___` 빈칸이 없다: `grep -rn '___' *.md docs/`
4. `.env.example` 있음, `.env`는 커밋되지 않음: `git ls-files | grep -x .env` 결과 없음
5. 비밀값 하드코딩 없음: `grep -rniE "password|secret|api_key" --include=*.py --include=*.js .` 결과 검토
6. 테스트 전부 통과 (개수 적기, 0개·전부 skip은 실패)
7. 빈 DB로 새로 띄워 헬스체크 200
8. `docker build` 성공 (실패하면 사유를 실행 안내 문서에 기록했는지)
9. 과제가 요구한 내보내기 결과가 있고 독립 검증기 위반 0
10. AGENTS.md가 최신(담당자 확인 사실 반영)
11. 제출 크기: `du -sh .`
12. `git status` 깨끗, 마지막 커밋 메시지에 결과 숫자

마지막에 "제출 전에 꼭 고칠 것"을 중요도 순으로 최대 3개 적는다.
