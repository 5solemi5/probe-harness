# 데이터 점검

이 단계는 **점검만** 한다. 구현·알고리즘은 만들지 않는다.

1. `python3 scripts/check_data.py <데이터폴더> --keys <키열들>`을 실행하고 출력을 그대로 보여 준다.
2. 데이터 설명 문서(열 정의·스키마)와 실제 파일을 대조한다:
   - 문서에 있는데 없는 열 / 문서에 없는 열, 자료형·형식(날짜·시각·숫자) 불일치
   - 키 중복, 파일 간 참조(외래키) 불일치, 매칭률
   - 허용 값 목록(상태·범주)에서 벗어난 값, 빈값·특수값과 빈도
   - 쌍·조합이 완전해야 하는 표(예: 출발지×도착지)의 누락
   - 시간대·날짜 범위가 파일마다 다른가
3. 보고 형식:
   - 표 1개 (항목 | 결과 숫자 | 문서와 일치 여부)
   - **데이터셋 검증 규칙 후보** 목록 (나중에 "적용 전 검증"에 그대로 쓴다)
   - **담당자에게 확인할 질문** 목록 (한 문장씩, 숫자 포함)
4. 결론을 쓰지 않는다. 모르는 것은 "확인 필요"로 적는다. 큰 파일을 통째로 출력하지 않는다.
