# 교차 리뷰 (수정 금지)

너는 이 저장소를 처음 보는 리뷰어다.

1. AGENTS.md의 성공 기준과 제약, REPORT.md/README.md의 주장을 읽는다.
2. 테스트와 메인 실행 명령을 직접 실행한다.
3. 다음을 검사한다:
   - 미래 정보 누수(판정·예측 시점 이후 데이터 사용), 평가 구간 분리
   - 하드코딩된 값·특정 사례 전용 분기
   - 예외 처리 없는 입력(빈 파일, 새 범주, 특수값)
   - 문서 숫자와 실제 실행 결과의 불일치
   - 제약 위반(외부 호출, 원본 수정, 비밀값 노출, 설치 필요)
4. 지적마다: 심각도(높음/중간/낮음) · 파일:줄 · 재현 명령 · 왜 문제인지 한 줄.
5. **코드를 고치지 않는다.** 마지막에 "가장 먼저 고칠 것 1개"를 고른다.
