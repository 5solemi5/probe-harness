# 데이터 점검

이 단계는 **점검만** 한다. 원인 추정, 판정 규칙, 모델은 만들지 않는다.

1. `python3 scripts/check_data.py <데이터폴더> --keys <키열들>`을 실행하고 출력을 그대로 보여 준다.
2. 추가로 확인한다:
   - 같은 키가 여러 번 나오는 이유가 될 만한 열(차수, 재작업, 버전)이 있는가
   - 음수·-1·-999·빈값 같은 특수값과 그 빈도
   - 시간 열의 시간대·형식 혼재, 기간이 파일마다 다른가
   - 파일 간 조인 키 매칭률
   - 결과가 정해진 뒤에야 채워지는 열(누수 후보)
3. 보고 형식: 표 1개 + "담당자에게 확인할 질문" 목록(각 질문은 한 문장, 숫자 포함).
4. 결론을 쓰지 않는다. 모르는 것은 "확인 필요"로 적는다.
