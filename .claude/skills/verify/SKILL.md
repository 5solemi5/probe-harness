# 완료 전 검증

완료를 보고하기 전에 아래를 **실제로 실행**하고, 명령과 출력 끝부분을 그대로 보여 준다.

1. 테스트: AGENTS.md의 검증 규칙에 적힌 명령. 통과 개수를 적는다.
   - 0개 실행, 전부 skip, import 오류로 수집 실패는 **실패**로 본다.
2. 메인 실행: 스크립트나 서버를 새로 실행한다. 웹이면 `curl -s localhost:3000/` 등으로 응답을 확인한다.
3. 숫자: 보고하려는 수치를 방금 실행 결과에서 다시 읽는다. 기억이나 이전 출력의 숫자를 쓰지 않는다.
4. 변경 범위: `git diff --stat`으로 의도하지 않은 파일이 바뀌지 않았는지 본다. 원본 데이터 파일이 바뀌었으면 즉시 멈추고 알린다.

보고 형식 (3줄):
- 한 일:
- 확인한 것 (명령 → 결과):
- 남은 의문·확인 못 한 것:

확인하지 못한 것은 "확인 못 함"이라고 쓴다. 추측으로 채우지 않는다.
